## Background 1

Production-grade SaaS churn reduction framework addressing voluntary churn (value gap, product-market mismatch, competitor switch, budget cut, project completion, poor experience, never activated) and involuntary churn (expired card 40-50%, insufficient funds 20-30%, bank decline 10-15%, account closed 5-10%, network error 5-10%). Uses a 5-stage cancel flow: cancel trigger, exit survey, dynamic save offer, confirmation, post-cancel. Save offers include discounts (30% 3 months cost 30% revenue, save rate 15-25%; 50% 2 months cost 50% revenue, save rate 20-30%), pause (1-3 months cost $0, save rate 25-40%), free onboarding (CS time $50-100, save rate 10-20%), downgrade (save rate 30-50%), feature unlock (save rate 5-15%). Dunning sequences recover 20-40% of churn. Win-back campaigns: day 7 success 5-10%, day 30 3-7%, day 60 2-5%, day 90+ 1-3%. Churn health scoring uses declining login frequency, feature usage dropping, support escalation, NPS <7, invoice dispute, champion leaving, contract renewal <90 days, competitor evaluation. Key metrics: save rate 10-15% good, 20%+ excellent; voluntary churn <3% good, <1.5% excellent; involuntary churn <1.5% good, <0.5% excellent; payment recovery 25-35% good, 40%+ excellent; win-back 5-10% good, 10%+ excellent; exit survey completion >70% good, >90% excellent; save offer acceptance 15-25% good, 30%+ excellent. Output artifacts: cancel flow design, exit survey, save offer system, dunning sequence, win-back campaign, churn scorecard, impact model.
