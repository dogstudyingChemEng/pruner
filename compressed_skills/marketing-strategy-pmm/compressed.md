• Define ICP with validation checklist.
• Develop positioning using April Dunford methodology.
• Build competitive knowledge base with proactive monitoring.
• Plan product launches by tier: Tier 1 (6-8 weeks, $50-100k), Tier 2 (3-4 weeks, $10-25k), Tier 3 (1 week, <$5k).
• Execute major launch with checklist and track metrics: traffic, engagement, pipeline, revenue.
• Equip sales with assets co-created with sales; track usage.
• Enter new markets systematically: US (50% budget, $1M ARR), UK (20%, $500k), DACH (15%, $300k), France (10%, $200k), Canada (5%, $100k).
• Validate 3+ paying customers in 90 days; pause if not.
• Localize content per market.
• Track PMM KPIs: product adoption >40% in 90 days, win rate >30%, sales velocity -20% YoY, deal size +25% YoY, launch pipeline 3:1 ROMI.
• Follow monthly rhythm: week 1 review metrics, week 2 create assets, week 3 support launches, week 4 report.
• Use proactive triggers for competitive intelligence.
• Output artifacts: positioning framework, GTM plan, competitive map, sales enablement.
• Verify all output quality.
• Troubleshoot: if positioning not customer language, rerun from alternatives; if win rate <25%, update battlecard monthly; if low pipeline conversion, reassess GTM motion; if assets unused, co-create with sales; if expansion fails, validate demand; if messaging inconsistent, build hierarchy.
